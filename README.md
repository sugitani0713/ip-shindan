# あなたのIPキャラ診断（顔出しなしYouTube向け）

占い × アンケートで、**その人だけのYouTube用IPキャラクター**を診断し、画像（PNG/SVG）とYouTubeでの勝ち筋、画像生成AI用プロンプトまで出力する無料Webアプリ。

- **無料・登録なし**
- **APIキー不要**：診断・描画・画像書き出しはすべてブラウザ内（外部通信ゼロ）
- **サーバー不要**：静的ファイルだけ。`index.html` をダブルクリックでも動く

## 使い方（手元で）

`index.html` をブラウザで開くだけ。

## キャラの系統（既存サービスとの違い）

Picrew・Charat等は「パーツを自分で選ぶ着せ替え」、VRoid Studioは重い3D、AI画像系は有料枠/APIキーが前提でした。
本アプリは**診断結果から人型パーツを自動で組み立て**、**APIキー不要**・**自前描画なのでライセンス確認不要**（商用YouTubeで使いやすい）が特長です。

- ゆるキャラ（マスコット） / アニメキャラ風（美少女・美少年イケメン） / Vtuber風（ヘッドセット・ネコ耳等）
- 性別は自由に選択可（自分と違う性別の架空キャラもOK）。結果画面で系統・性別を切り替えても、性格・ギャップ・口調は変わらず見た目だけが替わる
- 診断後は「簡易画像（PNG/SVG）」＋「ChatGPT用の決定版プロンプト（日本語/英語・画風5種）」＋「追撃プロンプト（表情差分6種・全身/三面図・サムネ16:9・アイコン1:1・Live2D用）」を出力。簡易画像を添付して使う3ステップ手順つき

## 診断の仕組み

1. **アンケート13問**＋自由記述3つ → 気質を5軸（温度 / エネルギー / 笑い / 個性 / 語りの深さ）で数値化
2. **占い**（任意）で気質に“傾き”を加える。影響は最大28%で、回答が主役
   - 日干（算命学・四柱推命の日柱）／ 太陽星座 ／ 数秘術ライフパス ／ 九星気学の本命星（アクセントカラー）／ 名前の母音・音の質感 ／ 前世（遊び）
3. 原型13種 × ギャップ設定 × 口調 × 名前候補 × 見た目（約10億通りの部品組み合わせ）を決定
4. あなたが書いた言葉を、キャラの設定・決め台詞に編み込む
5. 勝ち筋（形式・最初の10本・罠と対策・90日ロードマップ）と、サムネ視認性チェックを出力

「世界に一人だけ」にするための工夫：同じ入力なら同じキャラ（再現性あり）だが、名前・生年月日・全回答・自由記述のどれか1つが違えば別のキャラになる（1,500通りのランダム入力で重複ほぼゼロを確認済み）。

## ファイル構成

```
index.html        画面
css/style.css     デザイン
js/util.js        乱数・ユーティリティ
js/divination.js  占い計算（日柱は1900-01-01=甲戌基準、九星は立春=2/4で簡易切替）
js/data.js        設問・原型・ギャップ・文言
js/draw.js        ゆるキャラ(マスコット)のSVG描画エンジン
js/human.js       人型キャラ（アニメ風 美少女/イケメン・Vtuber風）の設計と描画
js/engine.js      診断・設計・文章生成・プロンプト生成
js/export.js      PNGカード／立ち絵（透過）／SVG書き出し
js/app.js         UI制御
```

## 拡張のしかた

- 設問を増やす：`js/data.js` の `DATA.questions` に追加（`d` は軸への加点）
- 原型を増やす：`DATA.archetypes`
- 見た目の部品を増やす：`js/draw.js`（耳・帽子・アイテム等）と `js/engine.js` の `design()` の重み表
- 将来：画像生成を“アプリ内で”行いたい場合は、ユーザー自身のChatGPT/Gemini等に貼る現行方式（プロンプトコピー）が、APIキー不要を保てる唯一の現実解

## 注意

占いはエンターテインメントです。「IP設計度」は *続けやすく覚えられやすい設計か* の指標で、再生数・収益を予測または保証するものではありません。
